Social Media Screen Time Dashboard
About the Project
This project analyzes social media screen time and explores patterns in daily usage.
Tools and Technologies
. Python
. Pandas
. Matplotlib
. CSV Dataset
Project Features
. Data analysis using Pandas
. Average screen time analysis by gender
. Bar chart visualization
Purpose
The purpose of this project is to understand social media usage patterns through data analysis and visualization.
